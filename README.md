# 📊 Integrated Industrial Project Financial Model (FAST Standard)

A comprehensive, fully dynamic 5-Year Financial Model and Valuation Framework designed for capital-intensive industrial projects. Built strictly in accordance with international financial modeling guidelines (**FAST Standard**).

---

## 🚀 Key Features & Architecture

The workbook is structured into 6 dedicated, fully linked modules:

1. **`01_Cover_&_Index`**: Project metadata, model control versioning, and table of contents.
2. **`02_Assumptions_&_Drivers`**: Centralized operational, macro, CAPEX, OPEX, and capital structure inputs.
3. **`03_Financial_Statements`**: 5-Year Integrated Statements (Income Statement, Balance Sheet, Cash Flow) with an automated **Audit & Integrity Check Block** ($Assets - Equity - Liabilities = 0$).
4. **`04_Valuation_&_DCF`**: Discounted Cash Flow (DCF) model featuring WACC calculation, Perpetuity & Exit Multiple Terminal Values, NPV, and IRR metrics.
5. **`05_Scenario_&_Sensitivity`**: Multi-variable sensitivity matrices (NPV vs. WACC & Growth Rate) alongside Base, Bull, and Bear scenario options.
6. **`06_Executive_Dashboard`**: High-level visual KPIs, charts, and summary metrics for executive decision-making.

---

## 🎨 Color-Coding Standards Applied

- **Blue Text**: Inputs and hardcoded parameters.
- **Black Text**: Calculations and internal formulas.
- **Green Text**: Cross-sheet links and external references.
- **Navy Headers**: Clean structural hierarchy with gridlines enabled.
